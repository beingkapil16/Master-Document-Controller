# Document Control System — Simulated EPC Project (Solar + BESS)

A self-initiated project simulating an end-to-end **Document Control system** for a fictional **50 MW Solar PV + 20 MWh BESS EPC project**, built to demonstrate hands-on understanding of the tools, workflows, and terminology used by Document Controllers in Solar, BESS, EPC, Power, and Manufacturing projects — including workflows typically run on **Aconex, SharePoint, or ProjectWise**.

All three components are cross-referenced to the same project, using the same document numbering system, so they function as one connected system rather than three standalone files.

## 1️⃣ Master Document Register (MDR)

A live register tracking **37 engineering, quality, and project management documents** across **8 disciplines** (Civil, Electrical, Mechanical, I&C, HSE, QA/QC, Procurement, Project Management).

**Includes:**
- Structured document numbering: `VSL-SLR-<DISCIPLINE>-<DOC TYPE>-<SEQUENCE>`
- Revision control workflow: **IFR → IFA → IFC/AFC → As-Built**
- A live **status dashboard** (Excel formulas + charts) auto-reporting document status, approvals, and overdue items
- Full revision history for 5 key documents, tracing each from first issue to construction release

**Sheets:** `MDR` · `Dashboard` · `Revision History (Sample)` · `Legend & Numbering Convention`

---

## 2️⃣ Transmittal & Document Distribution Log

A transmittal tracking system covering **13 transmittals**, formally logging document issue/receipt between Engineering, PMO, Site, and the Client/Consultant — cross-referenced directly to the MDR's Transmittal Ref column.

**Includes:**
- Full submission cycle simulation: issued for review → client comments → re-issue → approval → construction release
- Live dashboard tracking **Open / Closed / Overdue** transmittals
- A reusable blank transmittal cover-sheet template

**Sheets:** `Transmittal Log` · `Dashboard` · `Sample Submission Cycle` · `Legend & Template`

---

## 3️⃣ Document Control Procedure (SOP)

An 8-section governing procedure defining how documentation is controlled across the project.

**Covers:**
- Purpose & scope
- Roles & Responsibilities (RACI matrix)
- Document numbering convention
- Revision control rules
- Transmittal process
- Filing, retention & DMS structure
- Distribution matrix
- Reporting to Project Head & PMO
